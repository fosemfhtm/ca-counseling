# CA 학업·진로 상담 예약 사이트

GitHub Pages(정적 사이트)와 Google Apps Script + Google Sheets(저장소)로 동작하는 상담 예약 페이지입니다.

```
학생 ── github.io 페이지 ──(fetch)──> Apps Script 웹 앱 ──> Google 시트 [슬롯] [예약]
                                              └─> 알림 메일 (나 / 학생)
```

- 학생: 열린 시간 선택 → 내담자 기본정보·호소문제유형·주요 고민 입력 → 예약 확정
- 나: 시트에서 슬롯 생성, 예약 확인, **상담일지 초안 복사**, 취소 처리
- 같은 시간 중복 예약은 서버에서 잠금(Lock)으로 막고, 한 학번당 예정된 예약은 1건만 받습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 학생용 예약 페이지 |
| `config.js` | 제목, 안내 문구, Apps Script URL 등 **설정** |
| `apps-script/Code.gs` | Google 시트에 붙여넣을 백엔드 코드 |

## 설치 (처음 한 번)

### 1. Google 시트 + Apps Script

1. [Google 시트](https://sheets.new)를 새로 만들고 이름을 정합니다 (예: `CA 상담 예약`).
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 `apps-script/Code.gs` 전체를 붙여넣은 뒤 저장합니다.
4. 파일 맨 위의 `CONFIG`를 채웁니다. 특히 `COUNSELOR_NAME`(상담일지의 "상담자" 칸)을 채우세요.
5. 함수 목록에서 `setup`을 선택하고 **실행**합니다. 권한 승인 창이 뜨면 허용합니다.
   (“확인되지 않은 앱” 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르세요. 내가 만든 스크립트라서 나오는 경고입니다.)
6. 시트를 새로고침하면 상단에 **CA 상담** 메뉴가 생깁니다.

### 2. 웹 앱 배포

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형: **웹 앱** / 실행 사용자: **나** / 액세스 권한: **모든 사용자**로 설정합니다.
3. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
4. `config.js`의 `APPS_SCRIPT_URL`에 붙여넣습니다.

> 이 URL로는 "예약 가능한 시간"만 조회할 수 있고, 학생 개인정보는 외부로 나가지 않습니다.

### 3. GitHub Pages에 올리기

1. GitHub에 새 저장소를 만듭니다 (예: `ca-counseling`).
2. 이 폴더의 파일을 올립니다 (`.claude/` 폴더는 빼도 됩니다).
3. 저장소 **Settings → Pages → Branch: `main` / `/ (root)`** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/ca-counseling/`에서 열립니다.

## 관리자 페이지 (`admin.html`)

When2meet처럼 주간 시간표에서 드래그해서 상담 시간을 열고 닫는 페이지입니다. 주소는 `https://<아이디>.github.io/<저장소>/admin.html` 입니다.

1. 시트 메뉴 **CA 상담 → 관리자 키 만들기 / 보기**에서 키를 복사합니다.
2. 관리자 페이지에 키를 한 번 입력하면 그 브라우저에 저장됩니다.
3. 빈 칸에서 드래그하면 **열기**, 열린 칸에서 드래그를 시작하면 **닫기**가 됩니다. 시작 칸부터 끝 칸까지 사각형 범위 전체에 적용됩니다.
4. **저장**을 눌러야 반영됩니다.

- **장소 변경** 모드: 위쪽 장소 칸에 새 장소를 적고, 바꿀 칸(열림·예약됨)을 드래그한 뒤 저장합니다. 예약된 칸은 `예약` 시트의 상담장소도 함께 바뀝니다. 학생에게 따로 알리지는 않으니 직접 연락하세요.
- 기본 장소는 `교내 던킨도너츠`입니다. 학생이 예약할 때 다른 교내 카페를 고르면 그 카페가 상담장소가 되고, 상담일지의 카페이용내역에도 미리 채워집니다.
- 예약된 칸은 학생 이름이 표시되고, 드래그해도 지워지지 않습니다. 취소하려면 시트 메뉴를 쓰세요.
- 칸 단위(30분/60분)가 곧 상담 한 번의 길이입니다.
- 키가 유출되면 메뉴에서 새 키로 바꾸세요. 이전 키는 바로 무효가 됩니다.

## 운영

| 할 일 | 방법 |
|---|---|
| 상담 시간 열기 | **관리자 페이지**에서 드래그, 또는 **CA 상담 → 슬롯 일괄 생성…** (기간·요일·시간·상담 길이 입력). `슬롯` 시트에 직접 행을 추가해도 됩니다 (`날짜` 2026-10-06, `시작` 14:00 형식) |
| 특정 시간 막기 | `슬롯` 시트에서 `상태`를 `닫힘`으로 변경 |
| 예약 확인 | `예약` 시트 (새 예약마다 알림 메일도 옵니다) |
| **상담일지 작성** | `예약` 시트에서 해당 행 선택 → **CA 상담 → 선택한 예약 → 상담일지 초안**. 양식 순서대로 정리된 텍스트를 복사해서 붙여넣으면 됩니다 |
| 상담 후 기록 | `예약` 시트의 노란색 열(카페이용내역, 이용금액, 상담및조치, 관찰사항, 특이사항, 상담결과)을 채운 뒤 초안을 다시 열면 함께 들어갑니다 |
| 예약 취소 | 해당 행 선택 → **CA 상담 → 선택한 예약 취소** (시간이 자동으로 다시 열립니다) |

`예약` 시트 머리글 색:
- 파란색: 학생이 미리 입력한 칸 (학번~상세내용)
- 노란색: 상담 후 내가 채울 칸

## 상담일지 항목 대응

| 상담일지 항목 | 채워지는 곳 |
|---|---|
| 내담자 기본정보 (학번·이름·성별·학과·과정·국적·연락처) | 학생 입력 |
| 상담자 | `CONFIG.COUNSELOR_NAME` |
| 상담방법 | 항상 `대면상담` (`CONFIG.METHOD`) |
| 상담구분 | 학생이 "교수님·학과 등의 권유"를 고르면 `의뢰상담`, 아니면 `일반상담` |
| 상담일시·상담장소 | 선택한 슬롯 |
| 호소문제유형 | 학생이 고른 항목 (상담일지와 같은 분류) |
| 주요 호소내용 | 학생이 항목별로 적은 "주요 고민" (키워드 중심으로 다듬어서 사용) |
| 카페이용·상담및조치·관찰사항·특이사항·상담결과 | 상담 후 직접 작성 |

## 코드를 수정했다면

- **Code.gs 수정** → clasp로 올리고 기존 배포를 새 버전으로 바꿉니다 (URL 유지).
  ```bash
  clasp push --force
  clasp update-deployment <배포ID> -d "변경 내용"
  ```
  `.clasp.json`(스크립트 ID)과 `apps-script/private.gs`(상담자 이름 등)는 `.gitignore` 대상이라 GitHub에 올라가지 않고, clasp로만 Apps Script에 올라갑니다.
  clasp 없이 하려면 Apps Script에 붙여넣은 뒤 **배포 → 배포 관리 → (연필) → 버전: 새 버전 → 배포**.
- **웹 페이지 수정** → GitHub에 push하면 1~2분 뒤 반영됩니다.

## 로컬 미리보기

`APPS_SCRIPT_URL`이 비어 있으면 예시 시간으로 동작하는 데모 모드가 됩니다.

```bash
py -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다.

## 개인정보 참고

- 데이터는 내 Google 계정의 시트에만 저장됩니다. 시트 공유 범위를 꼭 확인하세요.
- 보유 기간이 지나면 `예약` 시트의 개인정보 행을 삭제하세요. 동의 문구의 보유 기간은 `config.js`의 `PRIVACY`에서 바꿀 수 있습니다.
- 학교나 기관에 개인정보 처리 관련 지침이 있다면 그에 맞게 동의 문구를 조정하세요.
